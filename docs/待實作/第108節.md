## 108. 立體化改版（2.5D）第一階段：3D 繪圖模組＋草原（2026-11-18 使用者確定方向）

狀態：可以實作。**本節只做 108.1–108.6（引擎模組＋草原 5 張圖）**；其他地區、農場、城鎮之後各寫一節。104.2 第 6 點（地圖拆層）**取消**：3D 畫法沒有 SVG 整張重畫的問題。

### 108.0 決定與範圍
- 使用者看過試做頁後決定：遊戲所有畫面改成 3D 立體畫法（有透視、高低地形、光影、空間感）。**角色、作物植株、怪物、果實、野生植株維持現在的 2D 圖**，在 3D 場景裡用「立牌」畫；**其他全部做成 3D**（地形、水、樹、石頭、建築、地標、裝飾）。
- 參考實作：`tools/proto_25d/index.html`（聊天室做的試做頁，three.js r128，可直接用瀏覽器打開；素材在 `tools/proto_25d/a/`）。裡面的地形、水、葉叢樹、立牌、影子、省電做法都已經過使用者確認，**照它的做法移植，不要另外發明**。
- 階段（每階段 iPhone 實測過才做下一階段）：1 引擎模組＋草原（本節）→ 2 森林、濕地、櫻花之丘、沙漠、雪原、秘境（每區一節）→ 3 農場 → 4 城鎮。
- **遊戲邏輯一律不動**：存檔、育種、打怪、出口、碰撞、多人同步、面板都照舊用現在的 2D 地圖座標（800×1100）。3D 只負責「畫」與「點擊換算」。

### 108.1 3D 模組
- three.js r128 放在 `lib/three.min.js`（已放好，MIT 授權），只有進入 3D 地圖時才載入；載入失敗、或裝置不支援 WebGL → 照舊用 SVG 畫法。
- 程式放在獨立檔 `js/w3d.js`（或照現有結構放一個區塊），對外只提供：`w3dEnter(地區,地圖)`、`w3dLeave()`、`w3dSetPlayer(x,y,方向,動作)`、`w3dSetOthers(list)`、`w3dSetMonsters(list)`、`w3dSetPlants(list)`、`w3dPick(螢幕x,y)→地圖座標`、`w3dDirty()`。
- 設定頁加「3D 畫面」開關（預設開；測試模式另有「強制 SVG」方便對照）。關掉就完全回到現在的 SVG 畫法，SVG 程式保留不刪。
- 座標：地圖 1px＝1/43 單位（角色顯示高 75px ≈ 1.75 單位）。地圖 x→3D x，地圖 y→3D z；高度由地形決定。
- 鏡頭：透視 45°，俯角三段（低 38°、中 50°、高 64°；預設低），跟隨角色、不超出地圖邊。遠處加淡霧。
- 光：半球光＋一盞從左上方來的太陽（和素材的明暗方向一致）。

### 108.2 地形
- 每張地圖產生一片高度網格（約每 0.5 單位一格）。高度來源：
  - 現有的 `cliff`＋`blocks` → 高台（崖頂一整片抬高約 3.8 單位，崖面陡）；
  - 現有的 `stairs` → **改成草地緩坡**（使用者指定：不要階梯，維持草原、做成可以走上去的斜坡），坡度約 0.3；
  - `rivers`、`lakes` → 往下挖（**只能往下挖**，見 108.4）；
  - 其他地方加很輕微的起伏，小路、出口附近壓平。
- 地面貼圖用 canvas 畫（照試做頁）：底色依 `REGION_CFG.ground`，加大片深淺色塊、草葉筆觸、小花、小石子；小路照現有路徑畫成柔和邊緣的泥土路；河岸畫濕泥與卵石；崖面畫岩石色塊。
- 「能不能走」照舊用現有 2D 碰撞（`regBlocked` 等）；緩坡要在 `walks` 或碰撞資料裡設成可走。

### 108.3 樹與景物（程式做的 3D，照試做頁）
- **樹**：葉叢卡片畫法（試做頁「樹：葉叢」）——樹冠由多團組成，共用整棵樹的圓滑明暗；表面鋪很多小片葉叢貼圖（每片 46 片小葉子），面向鏡頭那側較多；樹冠深處一顆小而暗的核心；樹幹有樹皮直紋與外擴樹根；約兩成開粉紅小花。
- **遠近兩種密度**：場景分成約 14 單位一塊，鏡頭附近用超密葉叢，遠處用較疏的版本（每 0.25 秒依距離切換）。
- 影子：太陽投影，**省電模式下影子只算一次**（見 108.6）。
- 草原物件對照（`GRASS_ART` 的鍵 → 3D 做法）：

| 鍵 | 做法 |
| --- | --- |
| round_tree、oak | 葉叢樹（oak 較大、團數較多） |
| flower_bush | 小團葉叢＋小花 |
| boulder | 圓滑石頭（多面體細分、非等比縮放、顏色微差），旁邊可加小石 |
| haystack | 程式做：圓柱＋圓頂，草稈色條紋 |
| log | 程式做：橫倒的樹幹（樹皮直紋、切面年輪色） |
| fence | 程式做：木樁＋橫桿 |
| bridge | 程式做：拱起的木板橋＋欄杆（照試做頁），可以走在橋上（高度跟著橋面） |
| sign | 程式做：木柱＋木牌，地名用 canvas 字貼在牌面 |
| well | 程式做：石砌圓井＋木頂＋轆轤 |

### 108.4 水（照使用者確定的〈水體呈現標準〉，所有地區都適用）
使用者原話：「水是液體應該要融合在一起。」「之後在每個地區地圖都要照這個標準。」
1. 相連的水是同一片液體：河、瀑布潭、池塘、湖交會處不能有接縫、切線、色差帶，也不能有陸地或沙邊隔開。
2. 岸線由地形決定：水面只是一片水平面（或沿河道的帶狀面），網格可以比水域大，邊緣藏在岸裡。
3. 水的樣子只看深度：載入時算一張深度圖（每點＝水面高度－地形高度，約 512×512，只算有水的區域），所有水面共用。淺處淺綠透明、深處藍；岸邊深度接近 0 的地方有白色水花並淡出；深度 0 直接不畫。
4. 相連水面高度要接得起來：河流進池塘前水面先降到和池塘同高；瀑布頂端直接接溪流盡頭、同寬。
5. 挖河道、池塘只能往下挖（取較低值），不能把旁邊的水底墊高。
6. 重疊的水面只畫一層（先畫的寫入深度，後畫的被擋掉）。河流水紋沿流向移動；池塘、潭用慢漣漪；瀑布加落水白花與水霧。
- 角色不能走進水裡（橋上除外），照舊用 `rivers`／`lakes`／`walks` 的碰撞。

### 108.5 立牌（角色、怪物、野生植株、道具點、其他玩家）
- 照試做頁「改善：開」：自訂著色器、底部稍暗、輕微暖色調、一起套霧；比較直立地站（傾角＝俯角×0.55，高度補償）；**照輪廓投射的影子**（斜向右下）；樹、石頭、房子底部長一圈小草小花蓋住接縫。
- 角色方向：正、側（左右鏡像）、背，走路正面兩張交替＋上下輕跳；換裝照現有 `av3SVG` 先畫成圖再當貼圖（同外觀快取）。
- 怪物：照第 105 節的動作（被打換圖、閃白、壓扁、打飛），改成在立牌上做。
- 點地面移動：用射線打到地形 → 換回地圖座標 → 照現有移動。另加左下角虛擬搖桿（照試做頁）。

### 108.6 省電（併入第 104.3 節的省電模式）
- 一般模式：解析度上限 2 倍、60 幀；省電模式：1.5 倍、30 幀。
- **畫面沒有變化就不重畫**（角色、怪物、鏡頭都沒動時停止繪圖）；水在省電模式下每秒更新約 12 次。
- 省電模式：景物不搖動、影子只算一次（固定在地上）。
- 切到背景、閒置照第 104.2 第 1、2 點。
- perf 面板（`?perf=1`）加「每秒畫幾次」。

### 108.7 待做 3D 模型（不在本節實作）
- 草原：樹屋 `stump_house`。
- 之後各地區的地標（神木、石祠、神殿、高腳屋、城鎮建築等）在各自那一節開始前列清單，用 AI 圖轉 3D 或手工建模，模型交給聊天室檢查畫風後再放進遊戲。模型來之前一律用 2D 立牌代替。

### 108.8 檢查與回報
- 先做草原入口一張圖，截圖回報（低、中、高三種視角），使用者看過再做其他 4 張。
- vm：地圖座標 ↔ 3D 座標換算來回一致；每張圖的出口、抵達點、植株點、道具點都在地形上、不在水裡；緩坡能走、崖面不能走。
- iPhone 實測（請使用者）：草原走一圈、過橋、走上緩坡、打怪 5 分鐘，回報 perf 面板「每秒畫幾次」、fps、手機溫度；一般模式與省電模式各一次。
- 「3D 畫面」關掉時，草原和改版前完全一樣。
