## 124. 稀有度改版：最稀有的一項決定等級（2026-11-20 使用者授權 Claude 定案；取代第 28.1 節的計分門檻）

狀態：可以實作，**排在第 123 節之後**。順序：124.1 先回報 → 124.2 → 124.3 → 124.4 檢查。照 CLAUDE.md 0.2.7：不自行 commit、push；全部做完存檔，BUILD 只升一次。回報的內容和本節的假設不同時，**先停下來問**。

背景：現在的稀有度是把各項特徵的分數加起來查表（28.1），玩家看不出為什麼這顆是稀有、那顆是史詩。改成一句話：**看這顆果實最稀有的那一項特徵。**這也讓供奉的說法對得上：進化要「傳說」的果實、神化要「神話」的果實。

### 124.1 先回報（不改程式）
1. 哪些地方用到稀有度：售價、經驗倍率、標本名額與命名、公告、紀錄榜、收藏櫃排序、委託條件、提示文字（`rarityHint`）、名品。
2. 現有全服標本（`rights`）各等級各有幾個（讀不到就寫讀不到）。
3. 用現行規則和新規則各抽 20,000 株野生植株（每區）與 8,000 株 F2，回報六個等級的比例對照。

### 124.2 新規則
一顆果實的等級＝下面符合的**最高**那一列：

| 等級 | 只要有其中一項 |
| --- | --- |
| 神話 | 雙夢幻色果皮＋專屬造型 |
| 傳說 | 完整夢幻色果皮＋專屬造型；雙夢幻色果皮；完整夢幻色果皮＋夢幻色花紋 |
| 史詩 | 完整夢幻色果皮；專屬造型 |
| 稀有 | 特殊造型；半夢幻色果皮；夢幻色花紋 |
| 少見 | 基本造型不是預設的那一種；有花紋 |
| 普通 | 其他（純色或中間色、預設造型、沒花紋） |

- 大小、完美度不影響等級。
- 同一個等級裡的排序（收藏櫃、紀錄榜）照舊用 28.1 的分數，分數不顯示。
- 提示文字改成直接說原因，例：「稀有：因為是特殊造型」「史詩：因為是完整的夢幻色」。原本「再加上花紋就會變成○○」的提示拿掉。
- 名品（金色徽章）不動。

### 124.3 跟著變的東西
- 售價、經驗倍率、公告（傳說以上）、偷菜成功率（第 125 節）都直接用新等級，倍率的數字不改。
- 標本：全部照新規則重算等級。**已經取得的標本、名字、編號全部保留**；重算後超過那一級名額的不移除，只是那一級暫時不能再有新的。名額數字（史詩 3、傳說 2、神話 1）這一節不改。
- 委託、每週大委託、NPC 故事裡「指定稀有度以上」的條件照新等級判定；當天、當週已經發出的照新規則重算一次是否符合。
- 第 114 節（還沒實作）的供品說明可以寫成「傳說的果實（夢幻色＋專屬造型）」「神話的果實（雙夢幻色＋專屬造型）」。
