### 127.2 種子袋
- **同外觀的成品自動合併**：同一種作物、外觀完全相同、都是成品的種子包，不論來源（收成、定型、買來的、別人送的），進種子袋時自動併成一格，顆數相加。
  - 例外：一包是買來的（帶 `bought`）、一包不是 → **不合併**（買來的不能交主線，混在一起會分不清）。
  - 玩家鎖定（★）的包照樣可以被併入，鎖定保留。
  - 既有的種子袋：載入時整理一次（新旗標，`newGame` 同步），併完跳一句「種子袋整理好了，空出 N 格。」
- **還會變的種子換一個樣子**：不是成品的種子包（育種中、雜交、野生採來的），格子畫成**一個布袋，袋口露出最多三顆小果實**，小果實是「種下去最可能出現的前三種外觀」。成品維持現在的畫法（單一顆果實）。
  - 一眼就分得出「種下去都一樣」和「種下去會不一樣」，不用看標籤。
  - 標籤文字（育種中、雜交、種原…）這一節不改。

### 127.3 標本名額
- 背景：外觀的組合有幾千種，名額照「每一種外觀」算，等於人人都拿得到自己的一格，名額沒有意義。
- 新算法：**史詩以上**的標本，名額照「組」算，同一組共用名額：
  - 果皮有完整夢幻色或雙夢幻色的：組＝**作物＋果皮的夢幻色**（雙夢幻色＝作物＋那兩種顏色的組合，不分先後）。
  - 果皮沒有夢幻色、因為專屬造型才到史詩的：組＝**作物＋專屬造型**。
  - 每一組的名額照那個標本的等級：史詩 3、傳說 2、神話 1（數字不變）。同一組裡不同等級分開算。
- **命名權**不變：每一種外觀的第一個取得者命名（所以同一組裡不同外觀可以各有名字）。
- 稀有以下不變（沒有名額、只寫自己的存檔）。
- **已經取得的標本全部保留**，包括改算之後超過名額的那幾組；那幾組只是暫時不能再有新的。編號、名字、交易紀錄都不動。
- 植株資訊裡「可以做成標本」的提示，名額滿時寫清楚是哪一組滿了，例：「翡翠色番茄的史詩標本已經滿了（3／3）。」
- 需要改 Firestore 規則的話，寫成**完整的一份**檔案（接續目前主控台上的版本），不要只給片段。
