### 133.2 一個狀態、三種記號
每一張任務在任何時候只會是下面其中一種，全遊戲用同一套顏色和記號：

| 狀態 | 意思 | 記號 |
| --- | --- | --- |
| 可以接 | 條件到了、還沒接 | 黃色「！」 |
| 進行中 | 接了、還沒做完 | 灰色「…」 |
| 等時間 | 要過一段時間才能繼續（例：地區故事第 3 步） | 灰色時鐘＋還要多久 |
| **可以完成** | **條件已經夠了，去找人或去交就結束** | **綠色「✓」** |
- 「可以完成」的判斷：
  - 要交果實或種子的：果實袋（或種子袋）裡**已經有足夠、符合條件的**（自己種的限制照各任務原本的規則）。
  - 要去某個地方、找某個人、獻滿祭壇的：照實際狀態，只差「回去說話」那一步時算可以完成。
- 這些記號出現在：NPC 頭上（城鎮與野外）、神之子頁那一格、任務面板每一張的左邊、祭壇。一位 NPC 同時有好幾張時，優先顯示綠色「✓」，再來黃色「！」。

### 133.3 指引
- **追蹤的任務**：畫面上常駐的那一行（第 116 節的 `#mqLine`）改成顯示「正在追蹤的那一張」，不限主線。
  - 預設追蹤主線；主線沒有進行中的步驟時，改追蹤最近接的那一張。
  - 任務面板每一張都有一顆「追蹤」，一次只追蹤一張；正在追蹤的那張標出來。
  - 那一行的內容＝那張任務目前這一步的提示，後面加進度（例：「交 6 顆大顆的南瓜給岳哥（4／6）」）。狀態變成可以完成時，整行變綠、文字改成「可以完成了：去找岳哥」。
- **點那一行就帶路**（擴充第 116 節的做法）：
  - 要找的人或地點在另一個地方 → 問「要去○○嗎？」（城鎮、農場、某個地區），按了就過去。
  - 已經在同一張地圖 → 那個人或那個點上方出現箭頭，一直留到走到為止。
  - 要去的是某一區裡面的某一張地圖 → 進那一區之後，通往下一張地圖的出口上有箭頭。
  - 目標是「種出某種果實」這種沒有地點的 → 打開那張任務的說明，寫清楚**要什麼、還差幾顆、怎麼來**（例：「白色的南瓜：野外沒有全白的，找帶白的讓它自己結種子」）。
- **任務面板**：
  - 排序：可以完成 → 可以接 → 進行中 → 等時間。每一類裡面主線在最前面。
  - 每一張顯示：狀態記號、標題、找誰、在哪裡、進度、獎勵。點開才看得到開場對白的重看。
  - 每一張下面兩顆按鈕：「追蹤」「帶我去」。可以交的那張，「帶我去」旁邊直接有「交」（交付畫面照第 117 節）。
  - 不能在面板裡直接交的（要回去和人說話的）就只有「帶我去」。

### 133.4 提醒
- **變成可以完成的那一刻**：跳一則提示「可以完成了：○○（任務名）」，點提示等於按「帶我去」。同一張只跳一次。
- **任務按鈕的徽章**：改成只算「可以完成」＋「可以接」的張數；有「可以完成」時徽章是綠色，否則黃色。沒有就不顯示。
- **每次進遊戲**：有可以完成的任務時，載入後跳一句「有 N 個任務可以完成了」，點了打開任務面板。一天最多跳一次。
- **等時間的任務時間到了**：跳「○○ 可以繼續了」。
- **每日委託快過期**：當天還有「可以完成」卻沒交的委託，在換日前 2 小時內進遊戲或還在線上時，跳一次「今天的委託還沒交」。每週大委託在最後一天比照。
- 提示用現行的提示框樣式，不擋操作；戰鬥中（131 做完後：血條不是滿的時候）先不跳，等回到安全狀態再跳。
- 設定頁加一個開關「任務提醒」，預設開；關掉後只留記號與徽章，不跳提示。
