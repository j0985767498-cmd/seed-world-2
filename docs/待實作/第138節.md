## 138. 介面改版第一步：共用樣式、主畫面、背包、種子詳細、任務面板（2026-11-21 使用者確認樣稿）

狀態：可以實作，**排在第 137 節之後**。順序：138.1 先回報 → 138.2 → 138.3 → 138.4 → 138.5 → 138.6 → 138.7 → 138.8 檢查。照 CLAUDE.md 0.2.7：不自行 commit、push；全部做完存檔，BUILD 只升一次；做完跑 `tload.js`。回報的內容和本節的假設不同時，**先停下來問**。
樣稿：聊天室的設計畫布「背包改版樣稿」（使用者看得到；本節已經把需要的數字都寫進來，不用去看）。

背景：使用者覺得介面難看又單調。聊天室看過截圖與程式後的結論：底子（木頭標題列＋奶油色）方向是對的，問題是①每一層都是同一種奶油色、棕色，沒有重點；綠色同時代表選中、標題、追蹤中、自己的訊息②字太多、圖太少③稀有度沒有顏色④幾種畫法混在一起（寫實木紋、平塗、亮面糖果紅）⑤入口太多、命名奇怪（種子袋裡有果實和素材；神之子藏在圖鑑裡）⑥兩套面板疊在一起時出現兩顆 ✕、標題列蓋住名字和金幣。參考：楓之谷的稀有度顏色、星露谷的背包格、動森的物品詳細。
原則：**不整套重做**，保留木頭＋奶油色，加上功能色、稀有度色、資訊減量；按鈕和面板一律用美術裡的深棕色粗外框，讓介面和角色、果實看起來是同一套畫法。

**這一節不做**：圖鑑分頁重排（只拿掉「神之子」分頁）、設定頁整理、其他面板（市集、製作、研究所…）的換皮。下一步再做。

3. 種子袋的分頁（種子袋、果實、素材、種原庫、查詢）與篩選（新的、全部、育種中、成品、種原）的程式位置；點一包種子現在打開什麼。
4. 種子格現在畫了哪些標籤（原始、迷你、成品、種原、新、數量、名字），各自的判斷。
5. CSS 變數與按鈕 class（`.btn`、`.fchip`、`.mini`、`.xbtn` 等）的現況；改 138.2 的共用樣式會影響到哪些畫面。

### 138.2 共用樣式
新增一組 CSS 變數，舊的 `--accent` 等保留給還沒換皮的畫面。

| 用途 | 值 |
| --- | --- |
| 內文字 `--tx` | `#3A2414`（取代灰棕細字；對比要夠，iPhone 戶外看得清楚） |
| 次要字 `--tx2` | `#6B5A43` |
| 外框 `--ol` | `#5A3416`（和美術的外框同色） |
| 面板底 `--pn` | `#FFF6E3`；卡片 `#FFFDF6`；淺框 `#E3D2B2` |
| 木頭標題列 | 上下漸層 `#A86F3A → #8A5528`，下緣 3px `--ol` |
| 主要動作（綠） | `#5DAF34`（漸層到 `#4E9F2C`），2～3px `--ol` 框，下方 3～4px 實色陰影 `#2F6E17` |
| 次要按鈕 | 底 `#FFF9EC`、2～2.5px `--ol` 框、下方 3px `--ol` 陰影 |
| 危險（丟掉、賣掉、清除） | 透明底、2px `#D9473A` 框、字 `#B4352A`；不用實心紅 |
| 選中的分頁 | 底 `#6E4320`、字 `#FFF3D6`（**不用綠色**） |
| 金幣 | `#F2C14E` |
| 關閉鈕 | 實心 `#D9473A`、3px `--ol` 框、白色 ✕、下方 3px `--ol` 陰影；**拿掉亮面高光** |

- **綠色只留給「主要動作」**（種下去、交、確定）。選中的分頁、標題緞帶、追蹤中、自己的聊天泡泡都不再用綠色：分頁用深木色；追蹤中用深棕粗框；自己的泡泡用 `#F1DDB8`。
- **稀有度色**（第 124 節的六級，全遊戲同一套；之後圖鑑、市集也用）：普通 `#B5A182`、少見 `#5DAF34`、稀有 `#3D86C6`、史詩 `#8D5BD1`、傳說 `#E3A21A`、神話 `#E0466B`。
- 字重：標題 900、按鈕與標籤 700、內文 500（字體照現行）。
- 觸控範圍至少 44×44。
