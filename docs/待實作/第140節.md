## 140. 主畫面按鈕重排（第 138 節的修正，2026-11-22 使用者確認「先這樣試試看」）

狀態：可以實作。修改第 138 節做好的主畫面（19c）。

### 140.1 為什麼要改（使用者在 iPhone 上看 19c 的回報）
- 右下角的綠色按鈕（育苗盤）蓋住了右邊那排的第 4 顆（選單）。
- 右邊那排太長：最常用的「背包」在最上面，離大拇指最遠；最少用的「選單」在最下面。
- 選單裡的朋友（每天要互助、偷菜）、圖鑑、裝飾（開墾也在這裡）其實不算少用。

### 140.2 新的排法（照有搖桿的手遊慣例：上面一條資訊列，下面左手搖桿、右手按鈕）
```
┌──────────────────────────────────┐
│ [頭像 Lv]  [金幣]  (朋友)(圖鑑)(布置)(地圖)(≡) │ ← 右上一排小圖示
│ [任務那一行]                                  │
│                                              │
│                                    (神之子)  │
│                                    (任務)    │ ← 右下大按鈕，越常用越靠近拇指
│                                    (背包)    │
│ (搖桿)                             (育苗盤)  │
└──────────────────────────────────┘
```
1. **右上一排小圖示**，由左到右：朋友、圖鑑、布置、地圖、選單（≡）。
   - 五個一樣大，點擊範圍至少 44×44 點，看起來比右下的大按鈕小一號；圖示下面不放字（或放很小的字，照第 138 節的樣式選一種，回報）。
   - 紅點：朋友＝今天還有朋友可以互助、或有新的好友邀請；其他照現有的紅點規則（有的話）。
   - 金幣那一塊放在這排的左邊。畫面寬度不夠放（例如 375 點寬的 iPhone SE）時，金幣改放到頭像下面，不要縮小圖示。
2. **右下三顆大按鈕**，由下往上：背包 → 任務 → 神之子。
   - 位置從育苗盤往上算：育苗盤離右邊、下面各 16 點（再加上安全區域）；背包的下緣在育苗盤上緣往上 12 點；三顆之間各留 12 點。**任何手機高度都不能互相重疊**。
   - 大小照第 138 節現在的大按鈕。
3. **選單（≡）只剩**：排行、設定、說明。
4. **種原庫併進背包**：背包的分頁變成「種子／果實／素材／種原庫」。種原庫分頁打開的就是現在的種原庫畫面（功能不變），只是入口換了。
5. **布置**＝原本的裝飾模式，加上開墾、主題布置（第 137 節）。點了進入布置模式，畫面下方出現一列工具：開墾、擺裝飾、主題、完成。長按綠色按鈕的圓盤裡原本的「開墾」保留，不要拿掉（老玩家習慣）。
6. 只在農場顯示「布置」；探索地圖、城鎮裡右上那排沒有「布置」，其他照舊。
