## 148. NPC 驚嘆號點了沒反應；點神之子改成看資訊（2026-11-22 使用者回報）

狀態：可以實作。

### 148.1 驚嘆號點了沒反應（bug）
- 使用者回報：NPC 頭上有驚嘆號，點了好幾次都沒有對話。
- 查清楚原因並修正，原因寫進回報。先檢查這幾種可能：
  - 顯示驚嘆號的條件和能開對話的條件不一致（例如任務在清單上但對話要求別的條件）。
  - 點擊被別的東西擋住：神之子、其他玩家、物件、透明的 UI 層蓋在 NPC 上面。
  - 點擊範圍太小，或用角色距離判斷，玩家站太遠時點了沒反應也沒提示。
- 修正後的規則：
  - **有驚嘆號就一定點得開**。點 NPC 時，NPC 的點擊優先於神之子、物件、地面移動。
  - 點擊範圍至少涵蓋 NPC 整個身體＋頭上的驚嘆號。
  - 玩家離太遠時：角色自動走過去，到了自動開對話（不要沒反應）。
- vm：每個任務 NPC 在「有驚嘆號」的狀態下呼叫點擊，都要開出對話。

### 148.2 點神之子：拿掉說話，改成資訊面板
- 點地圖上的神之子，不再冒對話泡泡，改成跳出「神之子資訊」面板。右下角的神之子按鈕也打開同一個面板。
- 面板內容（照現有資料，沒有的欄位先不顯示）：
  - 大圖、名字
  - 夢幻色（顏色名＋小色塊）
  - 階段（喚醒／進化／神化）和等級
  - 數值（照現有的戰鬥數值，例如攻擊、技能冷卻、加成）
  - 技能：名稱＋一句話說明＋冷卻
  - 下一階段需要什麼（如果現有資料有）
- 介面文字用玩家看得懂的說法，不用術語。
- 截圖：375×667 打開面板一張。
