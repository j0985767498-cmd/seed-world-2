## 186 補. 武器平衡收尾（2026-11-23）

狀態：可以實作，和第 187 節一起做（BUILD 只升一次）。20o 的結果：54 格有 22 格超出 ±10%，最大 +33%／−25%（改前是 +162%／−78%）。不再追 ±10%，做下面四個修正後收尾。

### 原因（看 `tools/sim186_20o.txt`）
1. **基準的劍在高階太強**：6 階單一目標，雙刀 −21%、斧 −16%、槍 −14% 都是「相對劍」變低。劍的覺醒「天十字」（十字 ×5.0 連發 3 次）是主因。
2. **扇**：1 階單一 +33%，6 階 −21%／−25%。技能 2 是回血、星星是愛心和甜甜圈，高階沒有傷害成長。
3. **雙刀** 1 階怪群 +26%：旋刃一次打身邊全部。

### 修正
1. 劍：天十字每次十字的倍率 5.0 → **3.4**（第 3 次長寬 ×2 不變）。十字斬（2～5 階）維持 5.0。
2. 扇：技能 2（癒花～花神之舞）**加上傷害**——回血的同時，r150 內的怪各受 ×2.2 傷害（覺醒 ×3.5）。扇的普通攻擊每下 1.76 → **1.5**。
3. 雙刀：旋刃 1～3 階每隻連斬 5 下 → **4 下**（4 階起照舊 7 下）。
4. 重跑模擬，劍以外的武器再用同一套搜尋法微調一次（限制照舊）。

### 收尾標準
- 合格線改成 **±15%**。跑完還超出的格子列在回報裡，不再調；之後照實際試玩的感覺改。
- 回報：6 張表、還超出 ±15% 的格子。
