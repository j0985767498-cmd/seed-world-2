## 191. 特效層：武器的普通攻擊與技能改播逐格特效圖（2026-11-23 使用者確定，先放進遊戲實測）

狀態：可以實作，排在第 190 節之後。照 CLAUDE.md 0.2.7：不自行 commit、push；BUILD 只升一次。
背景：程式畫的特效（`fxW`、`skFx`）使用者評 40 分。改用 Effekseer 免費特效（CC0）拍成的逐格圖，試玩頁 iPhone 實測可用。**使用者的評語：「剛好及格、可以用，之後還要再優化」**——所以這一節要做成「之後只換圖和 `plan.json` 就能改」，程式不用再動。
參考實作：`docs/待實作/第191節_參考實作.html`（聊天室的試玩頁：特效層、逐格播放、子彈、省效能畫法都在裡面，只有劍、槍、錘三把的寫死版本；邏輯照抄，資料改讀 `plan.json`）。

### 191.1 素材（已放進 repo）
- `assets/fx/<鍵>.webp`：每個特效一張逐格圖，每格 160px（少數 192，以 `plan.json` 為準）、8 欄、由左到右由上到下。透明背景。
- `assets/fx/plan.json`：
  - `fx[鍵]={n,cols,c}`：格數、欄數、每格像素。
  - `common`：共用（`meleeHit` 近戰命中、`crit` 爆擊、`tierUp` 升階、`starOk` 放星星成功、`heal` 喝補血藥）。
  - `weapons[作物]`：`atk`（普通攻擊）、`s1`、`s2`（各 3 組）。**s1 的三組＝1～2 階、3～4 階、5～6 階；s2 的三組＝2～3 階、4～5 階、6 階覺醒。**
  - 每一組是「時機 → 特效清單」。一筆特效：`{k, size, dx, dy, delay, fps, only, sy, rot, hold, loop, spread, count}`。
    - `size`＝顯示邊長，單位是人物格內像素（人物高 120；畫到地圖上要乘上人物的顯示比例）。`dx` 朝人物面向的方向為正（面向左就鏡射），`dy` 往上為負。
    - `fps` 預設 20；`delay` 秒；`only:1`＝只用發光疊加（`lighter`）畫；`sy`＝直向壓扁（貼地的圈）；`hold`＝播到最後一格後停留到這個秒數；`loop:1`＝循環前 8 格（飛行物）；`spread`＋`count`＝在半徑 spread 內隨機放 count 個。

### 191.2 時機（把每一招現有的事件接到這些名字）
| 時機 | 位置 | 什麼時候 |
| --- | --- | --- |
| `swing` | 自己 | 普通攻擊出手那一格（近戰刀光） |
| `muzzle` | 武器出手點（第 179 節 `mzMe`） | 遠程每次發射 |
| `proj` | 飛行物本身 | 取代現在程式畫的子彈、風刃、星光彈、飛彈；沿飛行方向旋轉 |
| `cast` | 自己 | 技能放出的瞬間 |
| `target` | 技能的主要落點（目標怪的位置或指定的點） | 主要那一下 |
| `pulse` | 每一個子落點 | 多段的招：連發的每一次十字、每一顆流星、每一發飛彈、連鎖爆破的每一爆、岩壁的每一塊、千影的每一隻、落雷的每一道 |
| `hit` | 被打到的怪身上（身體中間） | 每次這招對牠造成傷害；同一幀最多 6 個 |
| `tick` | 效果範圍中心或自己 | 持續型每跳一次（冥府之門、持續回血） |
| `ally` | 被補到血的隊友 | 癒花系 |
| `aura` | 自己，跟著走 | 持續狀態期間循環播（雷霆護身、雷神降臨） |
| `pod` | 浮游砲的位置 | 集中砲火、衛星砲 |
| `final` | 主要落點 | 這招的最後一下（收尾大爆、岩壁崩塌、岩之牢炸開） |

- 一招沒有某個時機就不播。現有 `skFx[招式]`、`fxW` 的程式畫法：**有 plan 的時機就不畫舊的**；plan 沒有涵蓋到的照舊（寫進回報）。
- 普通攻擊：近戰播 `swing`＋命中時 `hit`；遠程播 `muzzle`＋`proj`＋命中 `hit`。爆擊時另外加 `common.crit`。
- 5、6 階自己放的招：`final`（沒有 `final` 就 `target`）出現時畫面閃白 0.08 秒＋輕微震動（省電模式、`prefers-reduced-motion` 不做）。

### 191.3 特效層（照參考實作）
- 地圖上蓋一張專門畫特效的 `<canvas>`，在人物、怪物上面、傷害數字和介面下面；`pointer-events:none`。**解析度＝CSS 像素 ×1（不乘 devicePixelRatio）**——這是 iPhone 實測從 28 FPS 變 60 FPS 的關鍵，不要改。
- 每幀：清掉 → 照順序畫每個進行中的特效（`drawImage` 切格、位移、旋轉、縮放、透明度；`only` 用 `lighter`，其餘 `source-over`；**每個特效只畫一次，不疊第二層**）。沒有特效在播時不要跑這個迴圈。
- 座標跟著地圖鏡頭；3D 地圖（第 108 節）用同一個換算（世界座標 → 螢幕）。
- 圖用到才載入：裝備某把武器時載那把 `atk`、`s1`、`s2` 目前這一組會用到的圖；沒載完就退回舊的程式畫法（不要卡住、不要缺特效）。離開野外可以放掉。
- 上限：同時最多 40 個特效（超過就丟掉最舊的非自己的）。**別人的技能**（第 184 同步）：只播 `cast`、`target`、`final`、`proj`，不播 `hit`、`pulse`。省電模式：只播 `target`、`final`、`proj`。
