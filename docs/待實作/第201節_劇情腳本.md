# 第一季劇情任務 v3：序章～第三章（2026-11-23 使用者定案）

來源：v2（2026-11-23）＋使用者貼來的《主線劇本與系統腳本彙整》，照 Claude 指出的衝突修正：**序章的夢整段拿掉**、第一位神之子改在祭壇前選、神之子台詞改用彙整版（拿掉夢、「接住」、玩家欠神之子的語氣）。
實作規格：第 201 節。對白一格（｜分隔）不超過約 40 字；`{名}`＝玩家名字；`{神}`＝第一位神之子的名字。

**2. 漁村的委託**（漁民阿海）
- 阿海：最近湖水怪怪的，岸邊的作物都長不好。｜你在白樺林都種得出東西，幫我們看看？
- {名}：葉緣焦了，還帶鹹霜……得挑耐鹹的親本來配。
- **委託**（實際要交）：阿海說「村裡老人講，白皮、彎彎的甜瓜不怕鹹」→ **白色月牙形甜瓜 ×3**。交了之後老舵願意說話。

**3. 三條線索與神父的指引**
- 線索：紅樹林邊的泥腳印、被砍得很整齊的氣根、藏在蘆葦叢的無名小船。
- {名}：這艘船沒有漁村記號，船底還是濕的。
- 神父（快步走來）：我剛去東邊碼頭看過，有拖行的痕跡，｜還有一塊布勾在釘子上！賊可能往那邊去了。
- {名}：可是這裡有艘藏起來的船……
- 神父：小船不一定是他們的。晚一步就追不上了，｜你先去碼頭，我在這裡等。
- → 任務指引去「碼頭」（**倒木隧道**那張圖），只找到一塊爛麻布。回來時小船已經開走，只剩水波。
- {神}：白跑一趟。那個老好人神父，找人的眼光不太行耶。（傑柯改成：……嗯。祖琪改成：浪費時間。凱爾改成：神父也是好意。）

**4. 海蝕洞**（**沙洲盡頭**那張圖）
- 維恩帶研究員趕到：採樣船昨天全程在外海，都有紀錄。｜我對這片的水流有點研究，一起去堵人吧。
- 竊賊丟下裝果實的木盒跳海逃走。岩壁上刻著**被吞掉大半的日蝕**。
- {名}：這是什麼？不像這裡的文字。
- 維恩：我也沒在任何文獻看過。｜看來暗中搞鬼的，是我們還不了解的勢力。
- 記號記進筆記頁。

**5. 艾克希爾的新環**（不擋章節；第一次讓牠平靜下來時）
- 牠腳上露出閃亮的金屬環。取得【新的編號金屬環】。
- {名}：跟克洛諾斯那個一模一樣……只是這個新得多。
- 維恩（之後在研究所問起時）：那是研究所歷代學者追蹤大型生物用的。｜規格一直沒變。

**6. 歸還與季末**
- 果實送回教會，第三座祭壇亮起。小聚會：神父舉杯、維恩致意。
  - 神父：三處的果實都回來了。今晚好好放鬆吧。
  - 維恩：你帶來的變數，讓很多停了很久的事動了起來。
- 畫面切到城郊菜圃：阿土伯關著門擦農具。阿土伯：外頭熱鬧是他們的事。
- 第一季完成。下一站：櫻花之丘（神社回信，拒絕交出果實）。
