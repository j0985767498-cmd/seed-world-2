## 點仙子時的台詞（每隻 5 句，輪流）

| 仙子 | 台詞 |
| --- | --- |
| 番茄（開朗大姊頭） | 交給姊姊就對了！／今天的田也紅通通的，真不錯。／別灰心，下一代一定更漂亮。／抬頭挺胸，你可是我的主人！／累了就休息一下，姊姊幫你看著。 |
| 茄子（文靜優雅） | ……慢慢來，花會等你的。／今晚的月色，很適合散步呢。／您種過的種子，我都好好記著。／安靜一點的地方，我比較喜歡。／謝謝您喚醒我。 |
| 辣椒（熱血急性子） | 快點！再種一輪！／等什麼！衝啊！／這點小事，燒一下就好了！／我不累！再來！／哼，下一株一定更辣！ |
| 草莓（甜美愛撒嬌） | 主人～今天也要一起喔！／嘿嘿，摸摸頭好不好？／我最喜歡主人了～／這朵花跟我一樣可愛吧？／不要丟下我一個人嘛～ |
| 玉米（愛幻想的小發明家） | 我有個點子！要不要聽？／如果把種子裝上翅膀……／咦？剛剛那個是什麼？我去看看！／總有一天，我要飛得比雲還高！／天上的雲，好像可以拿來做東西。 |
| 南瓜（偷偷惡作劇） | 嘻嘻，什麼都沒做喔。／你的口袋好像怪怪的？／噓——別跟別人說。／我只是……借看一下而已。／要不要聽個恐怖故事？嘿嘿。 |
| 甘藍家族（外冷內熱） | ……我在。／別逞強。／田的事，我幫你看著。／哼，還算不錯。／冷了嗎？靠過來一點。 |
| 櫛瓜（酷酷的運動少女） | 熱身完了，走吧。／跟上我的速度。／贏了？那當然。／別停下來，繼續練。／今天狀態不錯。 |
| 甜瓜（瘋狂愛爆炸、會吃醋） | 嘿嘿，要不要看看會爆炸的那種？／砰！……嚇到了嗎？／好無聊～來點刺激的嘛！／這顆一定會開出很大的花火！／主人只能看我喔～ |

甜瓜吃醋（換成別隻、再換回她時，隨機一句）：你剛剛帶誰出門了？／哼，我才沒有生氣呢。／下次不准丟下我喔！

## 演出與公告用字

- 喚醒：「番茄仙子醒來了！」→ 取名框「幫她取個名字吧」（男生「他」）
- 進化：「緋莉雅進化了！」
- 公布欄（全服第一隻）：「○○ 喚醒了全服第一隻番茄仙子！」
- 名額滿：「全服名額已滿，可以向擁有者購買」
